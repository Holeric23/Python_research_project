# Анализ спроса на специалистов креативных индустрий в России по вакансиям из Telegram-каналов

## Описание проекта

Проект посвящён анализу вакансий креативных индустрий России на основе данных из Telegram-каналов.

Цель исследования — определить наиболее востребованные профессиональные направления, навыки и инструменты, а также оценить распространение требований к AI-инструментам.

## Источники данных

* ВДХЛ
* Design Hunters
* Digital Jobster

Общий объём данных после обработки — более 10 тысяч вакансий.
